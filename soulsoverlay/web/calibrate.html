Calibration

Pick a region on the right, then drag a box on the frame, or let Auto-find place the boss boxes from a frame with a boss at full health. The bar box should cover only the inside of the boss bar (no frame or ornaments). Add a second boss slot only for duo fights that show two bars.

Regions

    HUD scale

    Type the HUD scale from the game's options to move the boss and death boxes to match, then save. Auto-find fills this in too.

    Zoom

    Death template

    Load a screenshot with the death text fully visible, set the Death region, save, then capture. Until then a colour heuristic is used.

    Detection

    Run "Test detection" on a frame.
